# 中小学·高中知识图谱（离线改造版）

覆盖数学、语文、英语、物理、化学、生物、历史、地理、道德与法治、科学十个学科的知识图谱与自适应前置诊断，可离线使用（PWA / APK）。

当前数据：**4,128 个知识点 · 6,489 条先修边 · 16,659 道题 · 972 条课标条目**。

## 本版改动

1. **剥离全部在线功能**：删除账号登录、云同步、埋点统计、联盟带货页与全部推广位（「资源搜索」「儿童智商测试」横幅与结果页广告）。数据只留在本机，不联网、不上传。
2. **补齐九年级下册**：道德与法治 20 个知识点（3 单元 10 课 20 框，2026 秋统编版）+ 80 题；英语 40 个知识点（Unit 1–5 各 8 点，2026 秋人教版）+ 160 题。两者共新增 60 点 / 240 题、60 条先修边。
3. **修复知识点静态页的路径**：上游 kp 页用根绝对路径（`/assets/…`、`/kp/…`），部署到子路径（GitHub Pages）时样式与导航全 404；改为相对路径（`../assets/…`、`../kp/…`）。
4. **诊断页新增「分册总表」**：上册做一次、下册做一次诊断，自动合并成一张学年总表，按册与按单元列出「已掌握 / 不稳 / 薄弱 / 未测」。表跟随上方选中的年级联动，只测了上册时下册也会列出并标「还没测」。
5. **诊断页「范围」区块显式化**：整年级 / 上册 / 下册独立成框并加小标题，知识点数超过题量上限时提示「会有 N 个测不到，建议分册测」。
6. **统一导航为 8 项**：首页 / 知识图谱 / 诊断 / 档案 / 错题本 / 期末补漏 / 知识点索引 / 关于。

## 使用

手机浏览器打开本页 → 菜单「添加到主屏幕」，之后可离线使用。

## 已知局限

- 数据由 AI 生成初稿，未经教师审核；先修关系与题目答案仅供参考
- 语文 / 历史等识记题的正确性来自教材原文，未逐条核对页码
- 上游英语七、八年级仍有 28 个知识点的章节标为「待核」（未挂到具体单元）
- 知识图谱中数学、英语、物理三科沿用的是上游的先修边；其余七科为「同单元 / 同主题聚合」，跨单元的强依赖被弱化为 soft 边
